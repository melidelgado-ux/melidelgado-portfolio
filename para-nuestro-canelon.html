Experimentos · Micrositio personal

Del recuerdo al reencuentro

Una invitación digital para celebrar un cumpleaños y organizar un reencuentro. Un regalo personal que transforma la elección de una fecha en parte de la experiencia.

Ficha del proyecto

Tipo
Micrositio de cumpleaños y coordinación de evento
Objetivo
Invitar a elegir la fecha de un viaje grupal
Mi rol
Diseño de experiencia, contenido y desarrollo web
Tecnologías
HTML · CSS · JavaScript · Apps Script · Google Sheets

El desafío

Este micrositio de cumpleaños fue creado como regalo para una amiga que vive en Bahía Blanca. La invitación propone elegir la fecha de un viaje a Córdoba para reencontrarse con su grupo de amigas.

La experiencia tenía que sentirse íntima y hecha a medida, pero también resolver una necesidad concreta: recibir la fecha elegida y compartirla en privado con quienes organizan el viaje. El proceso debía ser simple para la cumpleañera y fácil de gestionar para el grupo.

Elegir cómo recibir la respuesta

Exploré tres alternativas para hacer llegar la fecha:

  • WhatsApp: podía notificar enseguida, pero el envío desde el sitio podía depender del dispositivo y requería resolver cómo abrir o iniciar la conversación.
  • Correo directo: mantenía la respuesta privada, aunque enviar correos desde una web necesita una integración de servidor o un servicio intermedio.
  • Google Forms y Apps Script: permitía registrar la fecha en una planilla y automatizar el correo al grupo.

Elegí implementar un formulario propio conectado a una aplicación web de Google Apps Script. Así, el micrositio conserva el control del diseño y el tono, mientras que Apps Script procesa la respuesta, la registra en Google Sheets y envía el correo a las personas organizadoras.

El formulario no es un Google Form insertado: es una interfaz propia conectada al servicio.

El repositorio también conserva un endpoint de correo con Resend como alternativa explorada. El flujo de envío de fechas documentado para el proyecto utiliza Google Apps Script.

01 · Portada y recuerdos

Empezar por la historia compartida

Un saludo de cumpleaños da paso a un poema personalizado y a una galería de fotos con estética de álbum. El poema puede desplegarse cuando la visitante quiera.

02 · La invitación

Revelar el plan del viaje

La segunda página presenta el origen, el destino, el horario y la descripción del viaje, junto con una playlist y un espacio dedicado a Albita.

03 · El álbum

Explorar las fotos

Las imágenes se presentan como polaroids. Al abrir una, aparece un visor con navegación, contador y opción de descarga.

04 · La fecha

Elegir y confirmar

La cumpleañera puede seleccionar una fecha a partir del 1 de noviembre de 2026. Al enviarla, recibe una confirmación con el día elegido y la fecha del viaje se actualiza en pantalla.

Cómo funciona el envío

  1. La usuaria elige una fecha en el formulario del sitio.
  2. El navegador envía la fecha a una aplicación web de Google Apps Script.
  3. Apps Script registra la respuesta en Google Sheets y envía un correo a las direcciones configuradas.
  4. El sitio confirma la recepción y guarda localmente la fecha para mostrarla si se vuelve a abrir en el mismo navegador.

La interfaz explica que la respuesta es privada y no se publica en el micrositio. También muestra estados del envío y permite volver a intentarlo si hay un error de conexión.

Diseño y experiencia

La dirección visual combina una base cálida y editorial con detalles artesanales: textura de papel, tonos crema, bordó, verde y rosa, y una combinación de tipografías expresivas y monoespaciadas.

La composición de álbum —fotos enmarcadas, captions manuscritos y pequeñas inclinaciones— ayuda a que el sitio se sienta como un recuerdo compartido. Las animaciones suaves y las transiciones acompañan el recorrido sin competir con el contenido.

Los controles cuentan con etiquetas y nombres descriptivos, y los estados se anuncian. En pantallas pequeñas, el visor de fotos admite navegación táctil.

El poema, la playlist y las referencias del grupo también forman parte del diseño: dan contexto afectivo a cada paso de la invitación.

Proceso

  1. Definir el objetivo: celebrar el cumpleaños y pedir una fecha para organizar el reencuentro.
  2. Comparar canales para recibir la respuesta: WhatsApp, correo y el flujo con Apps Script.
  3. Diseñar el recorrido en dos momentos: saludo y recuerdos, y luego la revelación del viaje.
  4. Implementar el formulario, la validación de fecha, el envío y la confirmación.
  5. Construir el álbum interactivo con navegación entre fotos y descarga.
  6. Personalizar poemas, mensajes y detalles del viaje con referencias del grupo.

Resultado y aprendizajes

El resultado es una experiencia personalizada que une una celebración con una tarea organizativa. La destinataria puede recorrer los recuerdos, descubrir el viaje y elegir una fecha en el mismo sitio; el grupo recibe la respuesta por correo y puede consultarla en una planilla.

  • El canal de respuesta también forma parte de la experiencia: tiene que ser cómodo para quien responde y útil para quienes organizan.
  • Separar la interfaz del procesamiento permite cuidar el diseño del formulario y resolver el registro y las notificaciones con otro servicio.
  • Una interfaz sencilla puede apoyarse en un flujo de datos que registre y comparta una respuesta de forma confiable.
  • Los detalles personales —el poema, las fotos, la playlist y las referencias compartidas— pueden darle propósito a una interacción funcional.
